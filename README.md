# Osteria Velluto

Concept website for a fictional Italian restaurant in Brera, Milan.
Design & code by Kisrak Kulacoglu. The restaurant and chef are fictional.

## Files
- `index.html` – the page content
- `css/style.css` – all the styles (colours are at the top, in `:root`)
- `js/script.js` – language switch (EN / IT / ES / FR), menu tabs, booking form, gift cards, scroll effects
- `images/` – all photos

## Run it
Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Publish on GitHub Pages
Push the folder to a GitHub repository, then Settings → Pages → Deploy from branch → `main` / root.
